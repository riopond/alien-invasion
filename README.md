# alien-invasion
Simple alien invasion game made using Python and Pygame.

The user will play as a rocket ship at the bottom center of the screen.
Using the left and right arrows keys, the player will be able to move
the ship from left to right.
Using the spacebar, the player will be able to shoot bullets that will
travel directly up.
The goal of the game is to shoot the aliens that will spawn when the
game is started, which will descend down.
Each round of the game spawns faster aliens.
To successfully pass a stage, the player must avoid the ship being hit
by the aliens and ensure none escape through the bottom of the screen.
The player has three chances (lives) to either be hit or let an 
alien escape.
If all three lives are lost, the game will end.
When the game ends, the number of rounds cleared will be displayed.
